# Data dictionary: county-month modelling table

Generated by `src/data/13_outputs.py` (it fails if a column is undocumented). One row per county per month, 47 counties x 2000-01..2025-12 = 14,664 rows; key = `pcode` + `year` + `month`.

Two tables are written. `data/processed/model_table_public.csv` has no EM-DAT-derived column: `flood_emdat` and every label/history column that used EM-DAT are dropped and the `*_public` columns are renamed to the standard names (`n_sources`, `flood_this_month`, `flood_corroborated`, `flood_next_month`, `county_flood_rate`). `data/private/model_table_full.csv` (git-ignored; EM-DAT licence) has all columns.

**Roles:** KEY = identifier; FEATURE = usable as a model input; LABEL (not a feature) = flood outcome for the same month or label metadata; TARGET = what we predict (next month).

**Label coverage warning (public table):** In the PUBLIC table (no EM-DAT) the flood labels thin out after 2018: the Global Flood Database's last flagged year is 2018, DFO's is 2010, and DesInventar has no records in 2017, 2018, 2019 (it is the only public source that reaches 2020-2025). So public floods in 2020-2025 are heavily UNDER-COUNTED: 17 flagged county-months (0.5%) against 732 (6.5%) in 2000-2019. A model trained and tested on the public labels will see a much lower flood rate in the test years than in training, so test-period recall, precision and base-rate comparisons are not trustworthy, and a low test flood count does not mean fewer floods happened. The private table adds EM-DAT, which covers the recent years, but it may not be shared.

**Baselines:** every 'normal', percentile and flood-rate uses training years 2000-2019 only. Lags/rolling windows were computed on the full available series before trimming to 2000-2025.

**Boundaries:** all Earth Engine features were computed on the OCHA COD-AB land-only county polygons (Lake Victoria, Lake Turkana and Lake Natron removed; Natural Earth 10m lakes v5.0.0). County adjacency and the GloFAS county maximum use the land-only COD-AB polygons (`data/reference/kenya_counties.geojson`); `kenya_counties_full.geojson` (lakes included) is for the dashboard map only.

**Area sources:** `area_km2` = polygon area from the Earth Engine export; `pop_density` uses KNBS county land area (`land_area_km2` in data/raw/population/county_year_population.csv). Land-only COD-AB areas agree with KNBS land areas within 7% for all 47 counties (median ratio 1.000).
